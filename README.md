# Musica Telegram Bot

Бот скачивает музыку и видео с YouTube и отправляет их в Telegram как MP3 или MP4. Работает с отдельными ссылками, плейлистами и YouTube Mix. Подписка на ИИ не нужна: бот запускается на вашем компьютере или сервере.

## Возможности

- До 10 ссылок на видео в одном сообщении.
- Выбор треков из Mix и плейлистов. Кнопка «Скачать 30 новых MP3» сама проверяет до 150 позиций, пропускает песни из чата и загружает максимум 30 новых в качестве 192 кбит/с. Если отправить тот же Mix снова, бот найдёт следующую порцию новых песен.
- Кнопка «Следующие 30» подгружает следующую часть списка, сохраняя ручной выбор. В ручном режиме за одну загрузку можно отметить до 150 треков.
- MP3 128, 192 или 320 кбит/с; MP4 до 360p, 480p или 720p. Файлы больше 50 МБ бот не отправляет.
- Исполнитель, название и обложка в MP3, если YouTube передаёт нужные данные.
- Защита от повторов по ID видео, основному исполнителю и названию песни. Кнопка «Почему скрыты» в Mix показывает, с какой песней найдено совпадение.
- Темы по исполнителям. Пока у артиста меньше пяти песен, они лежат в теме **NoName**. Фиты учитываются по первому исполнителю.
- Название темы исполнителя или **NoName** можно изменить командой `/renametopic Новое название` внутри этой темы. Песни остаются в ней; бот продолжает отправлять новые песни в ту же тему. Команда и ответ бота удаляются через 20 секунд.
- Поставьте ❤️ на сохранённый MP3: бот скопирует песню в тему **Избранные**. Уберите реакцию — копия исчезнет, оригинал останется в теме исполнителя. Команды `/favorite` и `/unfavorite` работают так же. Поиск и статистика доступны отдельно.
- Ссылка `/share` на подборку MP3: при открытии бот создаёт получателю темы **NoName** и по исполнителям и отправляет в них все сохранённые MP3 без новой загрузки с YouTube. `/unshare` останавливает дальнейшую отправку.
- Поиск YouTube без ссылки: `/findout исполнитель название`. Бот покажет до десяти видео с длительностью; отметьте несколько нужных, затем выберите один формат и качество для всех. Песни, уже сохранённые в чате, помечаются и повторно не скачиваются.
- Отмена загрузки и повтор только неудачных ссылок с сохранением выбранного качества. После успешной загрузки сообщение со ссылками и меню удаляются.

YouTube Mix подбирается динамически, поэтому список в боте может отличаться от списка на сайте. Сравнение песен по названию тоже не идеально: видео с совсем другим названием может пройти как новое.

## Что понадобится

- Python 3.10 или новее;
- `ffmpeg` и `ffprobe` для конвертации;
- `deno` для работы актуального `yt-dlp` с YouTube;
- токен бота от [@BotFather](https://t.me/BotFather).

На macOS зависимости можно поставить так:

```bash
brew install python ffmpeg deno
```

На Ubuntu/Debian установите Python, `python3-venv` и `ffmpeg` пакетным менеджером, а Deno — по [официальной инструкции](https://docs.deno.com/runtime/getting_started/installation/). На Windows установите Python, ffmpeg и Deno и добавьте их в `PATH`.

## Запуск

1. Создайте бота у @BotFather командой `/newbot` и сохраните токен.
2. Скачайте проект и установите зависимости:

   ```bash
   git clone https://github.com/zhanb6/Musica-telegram-bot.git
   cd Musica-telegram-bot
   python3 -m venv .venv
   source .venv/bin/activate
   python -m pip install -r requirements.txt
   ```

   На Windows создайте окружение командой `py -3 -m venv .venv`. Для активации в PowerShell выполните `.\.venv\Scripts\Activate.ps1`, в `cmd` — `.venv\Scripts\activate.bat`. Затем установите зависимости той же командой `python -m pip install -r requirements.txt`.

3. Скопируйте `.env.example` в `.env` и впишите свой токен после `TELEGRAM_BOT_TOKEN=`:

   ```bash
   cp .env.example .env
   ```

   На Windows файл `.env` можно создать вручную рядом с `bot.py`.

4. Запустите бота:

   ```bash
   python bot.py
   ```

5. Откройте бота в Telegram и нажмите «Начать». Выберите «🎵 Скачать музыку» → «🔗 По ссылке» или «🔎 Найти песню». Для поиска достаточно написать название обычным сообщением.

Бот работает, пока запущен `python bot.py` и компьютер подключён к интернету. История песен и избранное хранятся в `downloads.sqlite3` рядом с `bot.py`. При переносе того же бота на другой компьютер сохраните этот файл и `.env`. Они исключены из Git; токен в репозиторий не добавляйте.

Для автоматического отслеживания реакции ❤️ в личном чате добавьте в `.env` свои `TELEGRAM_API_ID` и `TELEGRAM_API_HASH`. Их получают в разделе API development tools на `my.telegram.org`. Бот создаёт отдельный сеанс для своего токена рядом с базой данных; вход в личный аккаунт Telegram ему не нужен. Без этих двух параметров команды `/favorite` и `/unfavorite` продолжают работать, но ручные реакции не отслеживаются.

## Запуск на Linux-сервере через Docker

Скопируйте `bot.py`, `requirements.txt`, `Dockerfile`, `compose.yaml`, `.dockerignore` и ваш `.env` в отдельный каталог сервера. Положите копию базы в `data/downloads.sqlite3`. Пока копируете базу, остановите старый экземпляр бота: одновременно запускать два экземпляра с одним токеном нельзя.

```bash
mkdir -p data
sudo chown -R 10001:10001 data
docker compose build
docker compose up -d
docker compose ps
docker compose logs --tail=50
```

Контейнер запускается без входящих портов и от непривилегированного пользователя. Лимиты: 0,75 CPU, 1 ГБ памяти, 512 МБ временного хранилища. Одновременно скачиваются не более двух файлов; остальные запросы ждут. `data/downloads.sqlite3` остаётся на сервере при пересоздании контейнера. Храните `.env` и `data/` вне Git и делайте резервную копию базы.

## Темы по исполнителям

У @BotFather включите **Bot Settings → Threads Settings → Threaded Mode**. После этого новые песни в личном чате с ботом попадут в **NoName** или в тему исполнителя. На пятой песне бот создаст отдельную тему и попытается перенести туда предыдущие сообщения. Давние сообщения могут остаться на прежнем месте из-за ограничений Telegram на удаление.

Если Threaded Mode выключен, MP3 и MP4 продолжат приходить в общий чат.

## Команды

Основные действия доступны кнопками: «🎵 Скачать музыку» открывает загрузку по ссылке и поиск на YouTube, «🎵 Моя музыка» — библиотеку. «Назад», «Отмена» и «Главное меню» завершают ожидание ввода. Ссылку на YouTube можно отправить в любом разделе. Если кнопки скрыты, нажмите встроенное «Меню» → «Открыть меню кнопок».

В поиске YouTube и Mix каждая песня показана отдельным сообщением с полным названием и своей кнопкой «Скачать». Она открывает выбор формата и качества только для этой песни; остальные результаты остаются доступны. Для загрузки нескольких песен отметьте «Выбрать для пачки» на карточках и воспользуйтесь общими кнопками под ними.

| Команда | Действие |
| --- | --- |
| `/menu` | Открыть меню кнопок |
| `/start` | Открыть главное меню |
| `/artists` | Исполнители и песни; кнопка «Скачать все MP3 ZIP» в своей библиотеке |
| `/zip` | Скачать свои сохранённые MP3 независимыми ZIP частями без ссылки `/share` |
| `/search запрос` | Найти сохранённые MP3 и MP4 по исполнителю и названию, в том числе с небольшой опечаткой |
| `/findout запрос` | Найти видео на YouTube и скачать несколько выбранных записей одним форматом и качеством |
| `/favorite` | Добавить песню в избранное ответом на аудио или видео бота; MP3 появится в теме «Избранные» |
| `/unfavorite` | Убрать песню из избранного ответом на неё; копия MP3 в теме исчезнет |
| `/favorites` | Список избранных песен |
| `/stats` | Песни по исполнителям и число песен до отдельной темы |
| `/share` | Получить ссылку на подборку сохранённых MP3 |
| `/unshare` | Отозвать ссылку и закрыть доступ |

Ссылки отправляйте обычным сообщением, без команды. Если файл больше 50 МБ, попробуйте меньшее качество. MP3 с битрейтом 320 кбит/с не улучшит звук, если исходник хуже.

`/search` ищет сохранённые MP3 и MP4 в истории чата и показывает тему каждого результата. Для MP4 без сохранённого MP3 отображается пометка **MP4**; кнопка отправки есть только у MP3. Нажмите песню, чтобы бот отправил сохранённый MP3 без новой загрузки с YouTube. Команда поиска удаляется, результаты обновляются в одном сообщении для каждого чата и темы; неиспользуемое сообщение исчезает примерно через две минуты или сразу после выбора песни/кнопки «Закрыть». В `/findout` можно отметить до десяти новых записей; после кнопки «Скачать выбранные» бот повторно проверит, какие уже есть в чате, и предложит один формат и качество для остальных. Брошенное меню поиска или выбора формата также удаляется после двух минут без действий; начавшуюся загрузку таймер не прерывает.

Ссылка `/share` действует для любого, кто её получит. В личном чате получателя бот с включёнными темами создаст темы и отправит все сохранённые MP3 по исполнителям; для артистов с менее чем пятью песнями используется **NoName**. Отправка идёт примерно по одному сообщению в секунду для каждого чата. Повторное открытие ссылки добавит только новые песни, а прерванная отправка продолжится после перезапуска бота. При выключенных темах остаётся меню исполнителей. История и избранное владельца не изменятся. Повторный `/share` возвращает ту же ссылку, пока вы не отправите `/unshare`. Отзыв останавливает дальнейшее копирование; уже отправленные MP3 остаются у получателей. Новый `/share` создаст другую ссылку. Команды доступа работают только в личном чате с ботом. При аварийном перезапуске между отправкой одного MP3 и сохранением отметки о нём бот может повторить именно этот MP3.

Свои MP3 можно скачать прямо из `/artists` кнопкой **«Скачать все MP3 ZIP»** или командой `/zip` в личном чате. Создавать ссылку `/share` для этого не нужно. Кнопка **«Скачать всё ZIP»** также есть под ответом `/share` и у получателя подборки. Бот собирает доступные MP3 в отдельные ZIP части до 45 МБ: сначала отправляет исполнителей с наибольшим числом песен, не смешивает исполнителей в одной части и перечисляет названия песен в подписи. Во время подготовки и отправки ZIP можно нажать **«Остановить ZIP»**; уже отправленные части останутся в чате. Служебное сообщение о ходе ZIP автоматически исчезает через 20 секунд после успешной отправки или остановки; при ошибках оно остаётся на 2 минуты. Сами ZIP файлы остаются в чате; отдельный список пропущенных песен удаляется через 2 минуты. Очистка служебных сообщений восстанавливается после перезапуска бота. Каждую часть можно сохранить и открыть отдельно в «Файлах» телефона. Бот готовит один архивный набор за раз, поэтому при нескольких запросах остальные ждут очереди. Telegram Bot API не позволяет боту получить сохранённый MP3 больше 20 МБ через `getFile`: такие песни, а также файлы с ошибкой получения, бот перечислит отдельно и не назовёт архив полным. При отзыве ссылки новые ZIP части по этой ссылке не отправляются; собственный `/zip` продолжает работать. Если бот перезапустился во время сборки, нажмите кнопку ещё раз; уже отправленные части останутся в чате. Если при отправке части пропал ответ Telegram, бот остановится и попросит проверить чат: часть могла дойти, поэтому он не отправит её повторно автоматически.

## Обновление

Остановите бота, затем выполните:

```bash
git pull
source .venv/bin/activate
python -m pip install -r requirements.txt
python bot.py
```

Скачивайте только материалы, на использование которых у вас есть право.
