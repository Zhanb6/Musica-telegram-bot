# 🎵 Musica Telegram Bot

Музыка и видео с YouTube прямо в Telegram: отправьте ссылку или найдите песню кнопками. Бот сохраняет библиотеку, распределяет песни по исполнителям и помогает скачать их снова без повторной загрузки.

- **Ссылки, поиск и Mix** — отдельная карточка песни со своей кнопкой скачивания.
- **MP3 и MP4** — выбор качества, обложки и музыкальные теги, файлы до 50 МБ.
- **Своя библиотека** — темы по исполнителям, избранное, защита от повторов и ZIP.
- **Подборки для друзей** — отправка сохранённых MP3 по общей ссылке.

## Быстрый запуск

Нужны Python 3.10+, ffmpeg, ffprobe, Deno и токен от [@BotFather](https://t.me/BotFather). Выполните из корня скачанного репозитория:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
```

Впишите токен в `.env` после `TELEGRAM_BOT_TOKEN=` и запустите:

```bash
python bot.py
```

В Telegram нажмите «Начать» → «🎵 Скачать музыку». Подробная установка, включая Windows, — в [инструкции запуска](docs/setup.md).

```bash

```
